# Keerthana Thiruppathi - Portfolio

A responsive personal portfolio website for myself, an aspiring software developer and AI/ML engineer.

## Built With

- HTML5
- CSS3
- JavaScript
- [Three.js](https://threejs.org/)
- [Font Awesome](https://fontawesome.com/)
- [Devicon](https://devicon.dev/)

## Getting Started

This is a static website and does not require a build step or package installation.

1. Clone or download the repository.
2. Open `index.html` in a browser.

For a local development server, run one of the following from the project folder:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000> in your browser.

## Project Structure

```text
myportfolio/
```

## Notes

- GitHub statistics are loaded from the GitHub API when the page is opened online.
- External fonts, icons, and Three.js are loaded from CDNs.
- Replace or update assets and profile links in `index.html` as needed.
